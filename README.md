# Java Pattern Programs

This repository contains various pattern printing programs written in Java. These are useful for improving logical thinking, mastering loops, and preparing for coding interviews.

## 📌 Patterns Included
- Star patterns
- Number patterns
- Hollow patterns
- Pyramid, diamond, and triangle shapes

## 💻 Language
- Java

## 🚀 Getting Started
Clone the repo and run any `.java` file using your preferred IDE or terminal.
